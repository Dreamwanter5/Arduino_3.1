# Arduino_3.1

## 📝 Descrição

Este repositório contém os arquivos e projetos desenvolvidos na unidade curricular sobre Arduino durante o primeiro semestre do terceiro ano do curso técnico integrado em informática.

## 🎯 Objetivo

O objetivo deste repositório é documentar e organizar os projetos práticos desenvolvidos com a plataforma Arduino, incluindo:

- Projetos de programação em C/C++ para Arduino
- Esquemas de circuitos eletrônicos
- Código fonte e exemplos práticos
- Experimentos e atividades realizadas em sala de aula

## 🛠️ Tecnologias Utilizadas

- **Arduino IDE** - Ambiente de desenvolvimento integrado para programação
- **Linguagem C/C++** - Linguagem de programação utilizada para Arduino
- **Componentes eletrônicos** - Diversos sensores, atuadores e módulos

## 📚 Estrutura do Repositório

Os arquivos estão organizados conforme o andamento do curso e as atividades desenvolvidas.

## 🚀 Como Usar

Para utilizar os projetos deste repositório:

1. Clone o repositório:
   ```bash
   git clone https://github.com/Dreamwanter5/Arduino_3.1.git
   ```

2. Abra o Arduino IDE

3. Navegue até o arquivo `.ino` desejado

4. Faça o upload para sua placa Arduino

## 📋 Pré-requisitos

- Arduino IDE instalado ([Download aqui](https://www.arduino.cc/en/software))
- Placa Arduino (Uno, Mega, Nano, etc.)
- Cabo USB para conexão
- Componentes eletrônicos específicos de cada projeto
